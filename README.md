# 5 部低幼英语动画主题分类地图

将以下五部英语启蒙动画按统一主题横向聚合：

- Didi's Day（31 集生活口语）
- Yakka Dee（1–7 季及特别篇共 155 集）
- Wow English（1–8 季主题 Unit）
- Big Muzzy（12 集主线 + 3 集词汇复习）
- Little Fox 小狐狸分级动画（L1–L7；930 个 MP4，1,006 条可识别标题索引）

选择主题后，只展示有匹配内容的动画，并列出集数/Unit、词汇重点、核心短句、内容范围或资源状态。Little Fox 按系列属性与英文标题关键词归类。支持动画筛选与中英文关键词搜索。

## Little Fox 数据口径

网盘文件夹标注合计 1,054 集。实际递归清单中核对到：

- 930 个 MP4 视频
- 76 条仅有 SRT 字幕、未发现 MP4 的标题记录
- 1,006 条可识别标题索引
- 48 集在 MP4/SRT 清单中均未发现，因此不在地图中伪造条目
