# 4 部低幼英语动画主题分类地图

将以下四部英语启蒙动画按统一主题横向聚合：

- Didi's Day（31 集生活口语）
- Yakka Dee（1–7 季及特别篇共 155 集）
- Wow English（1–8 季主题 Unit）
- Big Muzzy（12 集主线 + 3 集词汇复习）

选择主题后，只展示有匹配内容的动画，并列出集数/Unit、词汇重点、核心短句或内容范围。支持动画筛选与中英文关键词搜索。

## 本地运行

```bash
npm install
npm run dev
```

## 构建与测试

```bash
npm run build
npm run test:sites
```
